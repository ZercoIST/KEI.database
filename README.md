# KEI.database
用Gemini搭的网站，大概只有pc端使用体验好一些，手机端理论也能用但是我没测过
### 使用时请注意及时备份，在设置菜单中导出本地文件
\
主要功能
## 档案
评分库，网站的主要功能，也可用于管理进度\
支持从bangumi导入条目、自定义评分和评级标准等，评分标准和评级标准可以在设置中修改\
## TierList制作器
制作TierList\
支持从档案、bangumi导入条目，也可以按时间、标签批量导入或从本地文件批量导入\
支持修改表中图片比例、更改图片裁剪范围、自定义表格背景等等\
点击导出图片可以对导出的图片进行简单的编辑
## 九宫格
制作九宫格\
没什么好说的，除了没有批量导入跟TierList差不多，在设置里有一些自定义外观选项
## 颁奖
制作颁奖典礼\
奖项可以在档案中显示，别的东西和上面两个差不多
  
  
## 设置菜单
可以调整网站部分外观、各功能默认设置与模版，以及导出文件备份\
配色里有一点ai生成的私货
